# Special Hypertension Learning Academy

Static educational application for hypertension in pregnancy and stroke, based on the supplied 36-page presentation.

## Features
- Eight source-grounded lessons with slide-page references
- Interactive BP pathway practice
- Five MCQs
- Six advanced case simulations
- Historical vs later guideline comparisons, with external reference links

## Deploy
Import this folder as a static Vercel project. No build command is required.

## Clinical disclaimer
Educational only; not a patient-specific decision-support system. Source recommendations are predominantly from 2017–2018. Guideline comparison text is separately identified and requires clinical verification.
